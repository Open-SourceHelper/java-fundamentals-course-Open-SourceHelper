# Fundamentos de Java con una mascota virtual

Seis lecciones de Java para estudiantes de 12 a 17 años. Duración aproximada: 57 minutos.

[Ver el plan del curso](plan-curso.md) · [Ver la lista de reproducción](https://youtube.com/playlist?list=PLJeMlKFQeIqU&si=El0PIIh3nBqs1SFv)

## Cómo empezar

1. Abre la práctica de la lección en tu navegador.
2. Pulsa Run y observa la consola. En la lección 4, selecciona Interactive Console y escribe un apodo cuando lo pida el programa.
3. Prueba el reto. Si necesitas comparar tu resultado, abre la solución de esa lección.
